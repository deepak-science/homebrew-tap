# deepak-science/tap

Homebrew formulae for deepak-science projects.

```sh
brew install deepak-science/tap/kest
```

| Formula | Project |
|---|---|
| `kest` | [kestrel](https://github.com/deepak-science/kestrel): per-project wrapper for helm and terraform (`kest` + `kestci`) |

Formulae are written by each project's release workflow; don't edit them here.
